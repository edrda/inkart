# 🎨 Ink Art — Landing Page

Landing Page oficial da **Ink Art Design**, desenvolvida em **Vue 3 + Vite + TypeScript**, com foco em **performance, SEO local e experiência visual moderna**.  
O projeto foi construído para apresentar os serviços da empresa, seus diferenciais e portfólio de forma dinâmica e responsiva.

---

## 🚀 Tecnologias Utilizadas

- **Vue 3** (Composition API + `<script setup>`)
- **TypeScript**
- **Vite**
- **SCSS / CSS nativo com variáveis globais**
- **SwiperJS & animações customizadas**
- **Formspree** (integração com formulário)
- **Imagens otimizadas e SVGs**
- **Boas práticas de SEO (Santa Vitória do Palmar / Chuí)**

## 💬 Formulário de Contato

O formulário está integrado ao Formspree e inclui:

- Validação de campos obrigatórios
- Máscara de telefone
- Validação básica de e-mail
- Feedback visual para o usuário (mensagem de sucesso/erro)

## 🧠 SEO e Performance

O projeto foi otimizado para buscas locais relacionadas à Ink Art Design.

### Palavras-chave alvo:

- design gráfico Santa Vitória do Palmar
- comunicação visual Chuí
- fachadas comerciais Santa Vitória do Palmar
- adesivos, banners, letreiros, identidade visual Ink Art

### SEO implementado:

- Meta description otimizada
- Canonical tag
- Sitemap XML e Robots configurados
- URLs âncora amigáveis (#servicos, #galeria, etc.)
